🚌 TCC - Monitor de Lotação e Eficiência das Linhas de Ônibus
Trabalho de Conclusão de Curso Técnico em Desenvolvimento de Sistemas

📖 Descrição Geral
O sistema consiste em um aplicativo móvel nativo desenvolvido para as plataformas Android e iOS, utilizando o framework .NET MAUI, onde os passageiros reportam em tempo real o nível de lotação do veículo por meio de uma interface simplificada de toque único. Diferente de uma aplicação web convencional, o app mobile aproveita a integração profunda com o hardware do smartphone para realizar a validação automática via API de Geolocalização nativa. Isso garante que o relato seja efetuado apenas por usuários que estejam efetivamente no trajeto da linha.

🎯 Objetivo
Desenvolver e implementar, em um período de um semestre letivo, um sistema de monitoramento colaborativo para 5 linhas de ônibus específicas. A meta é atingir uma base de pelo menos 200 relatos semanais de usuários, a fim de gerar relatórios de eficiência que subsidiem a tomada de decisão da gestão de frota e reduzam o tempo de espera dos usuários em 10%.

🌱 Justificativa e Impacto Social
O projeto fundamenta-se na necessidade de democratizar o acesso a informações sobre o transporte público.

Alinha-se à ODS 11 (Cidades e Comunidades Sustentáveis) ao buscar tornar o transporte urbano mais eficiente.
Contribui para a ODS 8 (Trabalho Decente e Crescimento Econômico), uma vez que a otimização do deslocamento impacta diretamente o bem-estar do trabalhador.
📂 Estrutura do Repositório
O sistema possui duas frentes tecnológicas, estruturadas nas seguintes pastas:

📱 Pasta Mobile: Destinada à construção do aplicativo mobile (Android/iOS) utilizando o framework .NET MAUI com a linguagem C#.
⚙️ Pasta API: Destinada à lógica de servidor que processará as requisições dos smartphones e fará a comunicação com o banco centralizado em MySQL. Aqui ficará o projeto backend estruturado em Java, desenvolvido com foco em robustez no ambiente NetBeans.
